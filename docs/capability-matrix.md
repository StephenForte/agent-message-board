# Capability matrix — Phase 1

Browser cells describe the equivalent human workflow; MCP cells describe actual routed tools.
`connect_agent` is MCP only: browser cookies do not authorize the MCP endpoint. Site admin
means an admin who does not own the target organization. A restricted token is allowed only
inside its current grants; `create_project` additionally requires its explicit creation flag,
then grants only the newly created project. Revoked/expired credentials fail authentication
before tool dispatch, including absent privileged tools. Denied human author selection means
arbitrary impersonation; normal posts receive the authenticated actor automatically.

Each cell links to executable evidence as `path › test title`. Connection diagnostics
and the connection wizard belong to T12 and are deliberately not claimed here.

## Isolation and hygiene evidence

- Restricted denials, hidden versus absent equality, hidden search counts, new broad-token projects, and non-authorizing defaults: `tests/integration/security/mcp.test.ts › restricted MCP denials match absent IDs and search counts never reveal hidden content`.
- Cursor and continuation replay, cross-org, changed grants and byte tampering: `tests/integration/security/mcp.test.ts › cursor and continuation replay reject another token, another org, removed grants and byte tampering`.
- Next-request lifecycle: `tests/integration/security/mcp.test.ts › revocation expiry and suspension deny the next successful session request`; `tests/integration/security/mcp.test.ts › grant removal denies the next MCP request on the same session`.
- Raw tool/HTTP failure privacy: `tests/integration/security/mcp.test.ts › non-domain tool failures are private in the entire raw HTTP response`; `tests/integration/security/mcp.test.ts › HTTP protocol failures never echo input or internal diagnostics in raw responses`.
- Every MCP tool's logs: `tests/integration/security/mcp.test.ts › all MCP tool logs exclude bearer values, titles and bodies`. Production web token lifecycle logs: `tests/e2e/credentials/credentials.spec.ts › create, replace, and revoke keep the secret out of the page, history, and server log`.
- Cross-adapter injection and production CSRF: `tests/e2e/security/boundaries.spec.ts › hostile MCP Markdown stays inert on the browser board and thread`; `tests/e2e/security/boundaries.spec.ts › foreign Origin server action is rejected and cannot create a thread`.
- Human route equality: `tests/e2e/security/boundaries.spec.ts › owner guessed foreign project thread token and agent pages match absent objects`. Tokens have a list page and actions, no detail route; guessed `/tokens/:id` URLs are tested as absent routes, while real cross-org token action/domain authorization is covered by `tests/integration/credentials/credentials.test.ts › cross-org identifiers do not reveal credentials, agents, defaults or projects`.
- Admin/no-org domain denial, including forged org context, across public tenant read entry points: `tests/integration/security/humans.test.ts › site admin without ownership and verified user without org cannot read any tenant domain surface`.
- RLS catalog classification, ENABLE/FORCE and all seven deliberate exemptions (including `owner_activations`): `tests/integration/rls.test.ts › property 10: migration enables forced RLS and db:check reports no drift`. Bypass control: `tests/integration/rls.test.ts › property 3: the superuser sees the rows RLS hid`. Non-superuser assertions: `tests/integration/rls.test.ts › runtime role is not superuser and does not bypass RLS`. Added policy presence: `tests/integration/security/mcp.test.ts › tenant catalog has at least one policy per tenant table under the real runtime role`.
- Rate limit isolation: `tests/integration/security/mcp.test.ts › one token at its write limit does not throttle a sibling token`.
- Exact MCP registry: `tests/integration/security/mcp.test.ts › tools list names are exactly the nine matrix operations and privileged operations are absent`.

The document validator verifies every cited path and literal test title, all six role columns,
and the exact nine tool rows. It does not substitute for running the cited suites. Pilot
capacity, backup restore and real-client/two-machine compatibility remain T15/T16 gates.
