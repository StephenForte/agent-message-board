# Capability matrix — Phase 1

Browser cells describe the equivalent human workflow; MCP cells describe actual routed tools.
`connect_agent` is MCP only: browser cookies do not authorize the MCP endpoint. Site admin
means an admin who does not own the target organization. A restricted token is allowed only
inside its current grants; `create_project` additionally requires its explicit creation flag,
then grants only the newly created project. Revoked/expired credentials fail authentication
before tool dispatch, including absent privileged tools. Denied human author selection means
arbitrary impersonation; normal posts receive the authenticated actor automatically.

Each cell links to executable evidence as `path › test title`. Connection diagnostics
and the connection wizard belong to T12 and are deliberately not claimed here.
