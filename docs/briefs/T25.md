## The trap

1. **A global `"minimatch": "^11.0.1"` override** would also force eslint and its plugins from
   3.1.5 (CommonJS, a different API) to 11, which they do not support. Lint would break, or worse,
   silently match no files and pass. Scope the override.
2. **Lint going green because it checked nothing.** A minimatch change can alter which files ESLint
   or the TypeScript parser picks up. Green on its own proves nothing; plant a violation in a
   `.ts` file under `src/` and a `.tsx` file under `src/app/`, confirm `npm run lint` goes red on each
   with the expected rule, then delete them. Report both.
3. **`npm audit fix` (any form) or regenerating the lockfile.** Not allowed (D-040). The lockfile
   diff must be limited to the typescript-estree minimatch entry and anything it newly needs.
   Explain every changed package path in the PR body.
