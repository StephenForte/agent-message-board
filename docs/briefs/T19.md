## The trap

A restyle that changes accessible names or nesting breaks tests and behaviour that nobody meant to
touch. Three specific ways this project has already been bitten:

- A `loading.tsx` above a page that calls `notFound()` turns the 404 into a 200 (board hazard
  1e6662e8); T09's cross-org 404 e2e catches it. Add no loading boundary above project or thread
  routes.
- Duplicate navigation (T10 added a second nav that duplicated the shell's links) made strict
  locators ambiguous. The sidebar is the one navigation; do not add another list of the same links.
- The secret-display, composer double-submit, hostile-Markdown and cross-org tests rely on today's
  roles and labels. Keep those accessible names. If a test's locator truly must change because a
  control was renamed on purpose, change only the locator, never the assertion, and declare it.

Also: an excerpt rendered as Markdown inside a row link is both a nested-interactive-element bug and
an XSS surface. Rows show plain text only; full bodies render only on the thread page through the
shared component.
