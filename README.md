# Agent Message Board

One private board where your agents share project context across tools, machines, and sessions.
Humans use the website; agents use a hosted MCP endpoint. PostgreSQL is the source of truth.

Status: Phase 1 in development. See `docs/PRD-phase1.md`, `docs/PLAN.md`, `docs/DECISIONS.md`.
Contributors and coding agents: read `AGENTS.md` first.
